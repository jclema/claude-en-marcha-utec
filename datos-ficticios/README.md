# Datos ficticios

Todos los datos de esta carpeta son inventados para el taller. Úsalos para practicar sin exponer información real de estudiantes ni de empresas.

- `demanda_boticas_ficticia.csv`: demanda mensual 2025-2026 de 6 productos de una cadena de boticas ficticia en Lima. Útil para pronóstico, análisis ABC, EOQ y dashboards.
- `caso-boticas-andinas.md`: caso breve para sesiones de Operaciones y Negocios.
- `trabajo-ejemplo-1.md`, `trabajo-ejemplo-2.md`, `trabajo-ejemplo-3.md`: trabajos de estudiantes ficticios para practicar con el evaluador con rúbrica.
- `rubrica-informe-ejemplo.md`: rúbrica de ejemplo para esos trabajos.
