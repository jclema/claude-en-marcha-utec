# Aportes de los docentes

Sube aquí tus Skills, specs y herramientas en una carpeta con tu usuario de GitHub: `aportes/<tu-usuario>/`.

Desde la web de GitHub (en Chrome, con tu sesión iniciada y la invitación de colaborador aceptada):
1. En tu computadora crea una carpeta con tu usuario de GitHub y mete ahí tu `spec.md`, el HTML de tu herramienta, el ZIP de tu Skill (si la creaste) y un `README.md` corto.
2. Entra a esta carpeta `aportes` en GitHub y haz clic en **Add file > Upload files**.
3. Arrastra la **carpeta completa** (no los archivos sueltos) a la zona de carga. Así queda en `aportes/<tu-usuario>/`.
4. Mensaje de commit: `Aporte de [nombre]: [qué subes]` y **Commit changes**.

Si ves un error 404 o no aparece el botón **Add file**, aún no aceptaste la invitación: búscala en tu correo ("invitation to collaborate") o entra a https://github.com/notifications.

Para instalar la Skill de un colega: abre su carpeta, haz clic en el ZIP, descárgalo con el ícono de descarga y súbelo en Customize > Skills > + > Upload a skill.

Incluye un `README.md` corto: qué es, para qué curso sirve y cómo usarlo. No subas datos reales de estudiantes.
