# Claude en Marcha UTEC

Recursos del workshop aplicado de Claude Desktop para docentes de la Facultad de Ingeniería Industrial y Negocios de UTEC (14 de noviembre de 2026). Facilitado por Juan Camilo Lema, [JoeWork.co](https://joework.co).

**Guía del participante:** [abrir en Google Docs](https://docs.google.com/document/d/1DRpriWOaWGNzSqTLSSxME55HejNPiJ_S_DEVI4o58CE/edit)

## Qué hay en este repositorio

|---|---|---|

## La escalera

Prompt → Contexto → Proyecto → Skill → Tarea programada → Agente y subagentes → Herramienta propia (SDD + Claude Code)

Regla de oro: usa la solución más simple que resuelva el problema. Fuente: [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents).

## Cómo aportar
Cada docente sube su trabajo a `aportes/<tu-usuario-github>/`. Ver [aportes/README.md](aportes/README.md).
